# Haochen Liang — Academic Homepage

Live site: https://flowerinzdf.github.io/

Static academic website. GitHub Pages publishes the root of the main branch.

## Updating

- Edit index.html for biography, publications, education and awards.
- Edit style.css for appearance.
- Replace CV.pdf to update the downloadable CV.
- Replace portrait.jpg to update the profile photo.
- Commit changes to main; GitHub Pages redeploys automatically.

The .nojekyll file preserves plain HTML hosting. No installation or build is needed.
